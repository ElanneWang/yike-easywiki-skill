> - 多个并行工作流

## 阶段性变更

| 日期 | 变更类型 | 内容 | 来源会议 |
|------|---------|------|---------|
| | 新增 / 强化 / 修正 / 冲突 / 失效 | | |

变更类型的含义：
- **新增**：出现了之前没有的共识
- **强化**：新证据支持了已有共识
- **修正**：已有共识被改动了，必须写清"原来是什么"
- **冲突**：新信息和已有共识矛盾，暂不裁决，进待确认
- **失效**：某个旧共识不再成立，保留行并标 `superseded`
