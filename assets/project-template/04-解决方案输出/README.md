# 解决方案输出

> **确定性输出**：客户已确认、可对外引用、可追责的东西放这里。
> 与 `02-沟通记录/` 的区别：沟通记录是过程，只增不改；这里是结果，定稿即归档。

## 归档规则

1. **定稿才进这里**。还在讨论中的方案留在 `02-沟通记录/` 或 `03_方案对齐.md`，不要提前归档。
2. **不覆盖旧版本**。新版本另存，文件名带日期：`20260903_方案_v1.md`、`20260910_方案_v2.md`。
3. **标注状态**。每份文件开头写明：客户确认日期、确认人、是否可对外引用。
4. **需要长期存档的单独标出**。合同、验收单、正式报价这类可能被当证据的文件，在下方清单里标 ⚖️。

## 与项目状态的关系

输出定稿后，必须回到 `03_方案对齐.md`：

- 把对应决策的状态从 `proposed` 改为 `confirmed`
- 在「阶段性变更」记一行
- 更新 `README.md` 的当前进展
