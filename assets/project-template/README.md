## 阅读入口

**第一次接触这个项目，按这个顺序读**：

1. 本文件（当前进展 + 关键卡点）
2. [03_方案对齐.md](03_方案对齐.md)（共识、决策、待确认）
3. [02-沟通记录/](02-沟通记录/) 里最近一次会议的**总结**（不用读原文）
4. 需要追溯某个判断的来龙去脉时，再回原文

**按角色**：

| 角色 | 必读 | 按需读 |
|------|------|--------|
| 接手这个项目的人 | 当前进展、03_方案对齐、最近一次会议总结 | 全部沟通记录 |
| 参与方案的人 | 03_方案对齐、01-项目上下文 | 相关会议原文 |
| 只想知道进度的人 | 当前进展 | 无 |
