## 核心设计

- 双向关联：概念与案例互相引用，输出文档引用依据规则
- 分级约束：必须双向 / 建议双向 / 单向引用
- 页面模板：统一的 frontmatter + 正文结构

> 场景四生成时，本节按实际情况改写：不写双向关联，改写为「过程与结果分离」（`02-沟通记录` 只增不改、`04-解决方案输出` 定稿即归档）与三条核心纪律（过程只增不改、每次会议必须回写状态页、状态必须标 `compiled_through` 日期）。
>
> 场景五生成时，本节改写为「多人共建 + 版本治理」：每条内容必须有 `type` / `status` / `owner` / `review_by`，废止版本移入 `99-归档/`；业务线用 `domain` 字段而非目录。
>
> 场景六生成时，本节改写为三条底线（`raw/` 只增不改、每个页面能回溯来源、`index.md` 与实况一致），并写清顶层分类是按什么维度分的。

## 工具（可选）

详细使用方法请参阅 skill 的 `references/media-ingestion-guide.md`。
